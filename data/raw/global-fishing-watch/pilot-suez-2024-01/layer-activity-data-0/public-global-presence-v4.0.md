
## AIS dataset
### Description


Filters: vessel_type = 'cargo' and  timestamp >= parseDateTimeBestEffort('2024-01-01') and timestamp < parseDateTimeBestEffort('2024-02-01')
Resolution: low (10th degree resolution)

### Format
- GeoTIFF
- CRS: EPSG:4326 - WGS 84 - Geographic
